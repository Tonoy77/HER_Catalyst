# Dual-atom catalysts on Si(111) for the hydrogen evolution reaction: DFT and machine-learning data

Data and code supporting research on **"Hydrogen evolution catalyst design on dual-atom Si(111) systems through high-throughput first-principles and interpretable machine learning"**.

## 1. What this archive contains

All 59 TM1TM2/Si(111) dual-atom systems (3d, 4d, and 5d transition metals, alkali/alkaline-earth metals, and early lanthanides) with, for each system:

- DFT hydrogen adsorption energies, zero-point energy corrections, and Gibbs free energies (ΔG_H*)
- Bulk formation and anchoring energies
- Work function, d-band centres, Bader charges, and net spin magnetic moments
- RPA dielectric and optical data, and COMSOL Multiphysics 6.3 field and dissipation profiles
- Relaxed Cartesian coordinates of all atoms (embedded as JSON in the master table)
- The machine-learning datasets and the Python script used to train and evaluate the models

## 3. Quantities and units

| Quantity | Symbol | Unit | Definition |
| :--- | :--- | :--- | :--- |
| H adsorption free energy | ΔG_H* | eV | ΔE_H + ΔZPE − TΔS, relative to ½H2(g) at 298.15 K, 1 bar |
| Electronic adsorption energy | ΔE_H | eV | E(slab+H*) − E(slab) − ½E(H2); E(H2) = −6.759123 eV |
| Zero-point correction | ΔZPE | eV | ZPE(H*) − ½ZPE(H2); ½ZPE(H2) = 0.1334 eV |
| Entropy term | −TΔS | eV | +0.2019 eV at 298.15 K |
| Bulk formation energy | E_form,bulk | eV | E(TM1TM2/Si(111)) + 2µ(Si) − E(Si(111)) − µ(TM1) − µ(TM2) |
| Anchoring energy | E_anchor | eV | E(TM1TM2/Si(111)) − E(Si(111)) − E(TM1 atom) − E(TM2 atom) |
| Work function | Φ | eV | V_vac − E_F, on the functionalised catalytic surface |
| d-band centre | ε_d − E_F | eV | First moment of the projected d-DOS relative to E_F |
| Bader net charge | q_TM | e | Z_A minus the valence charge enclosed in the Bader basin |
| Total magnetisation | M_tot | µB | Net spin magnetic moment (spin-up minus spin-down) per supercell |
| Power dissipation | P_diss | GW m⁻³ | ½ω ε0 ε2 \|E\|², under AM1.5G illumination |

### Special feature handling in machine learning datasets
- **Na d-band centres (`dos_d_band_tm1_eV`):** Sodium (Na) is an alkali metal lacking valence d-electrons. In ML feature tables, the d-band centre for Na sites is assigned the library mean value (-1.4486 eV) as a numerical feature imputation for non-transition metal TM1 sites.
- **p-block metallic radii (`metallic_radius_TM2`):** Elements Bi, Sb, Se, and Te are p-block elements/non-metals for which standard metallic radii are not defined; a numerical value of `0.0` is used as an explicit non-physical placeholder.

## 4. Computational details

- **DFT Framework:** VASP 6.4.2, projector augmented-wave (PAW) method, spin-polarised PBE functional, uniform protocol for all 59 systems.
- **Tolerances:** Electronic energy convergence tolerance is 1e-5 eV; force convergence tolerance on ions is 0.05 eV/Å. (Note: the ±0.15 eV threshold referenced in discussion denotes the operational catalytic screening window for ΔG_H*, distinct from the 0.05 eV/Å DFT force convergence criterion).
- **Settings:** Plane-wave cutoff 400 eV; Γ-centred 2 × 2 × 1 k-mesh for ionic relaxation and screening, 6 × 6 × 1 for RPA optical calculations; Gaussian smearing 0.05 eV; dipole correction along the surface normal.
- **Pseudopotentials:** Standard VASP PAW PBE potentials (VASP 6.4.2 recommended distribution). Due to the VASP license agreement, proprietary POTCAR files cannot be redistributed; calculations are fully reproducible using the standard VASP PBE PAW library.
- **Optics:** COMSOL Multiphysics 6.3 (wave optics module), AM1.5G reference solar spectrum (ASTM G173).

## 5. Reproducing the machine-learning results

The script trains random forest, gradient boosting, support vector, and XGBoost regressors along with an unweighted consensus ensemble to predict ΔG_H* from the 35-feature candidate pool. A fixed seed (17144) produces the 41/18 train/test split, which identically matches the annotated `partition` column in the CSV files. Feature selection (7 forced DFT electronic descriptors, 7 elemental descriptors chosen by F-regression) is fitted on the training fold only.

```bash
cd 05_Machine_Learning_and_Code
pip install -r ../requirements.txt
python train_and_evaluate_ml.py
```

Tested with Python 3.12.10, numpy 2.5.4, pandas 3.1.0, scipy 1.18.1, scikit-learn 1.9.1, xgboost 3.4.1, matplotlib 3.11.2. The script validates partition alignment, calculates benchmarks and residual statistics, and saves the reproduced parity plot (Fig. 4a), PFI rankings (Fig. 3c), and Pearson correlation matrix (Fig. 3e) into `reproduced_figures/`. (SHAP feature attribution data for Fig. 3d is curated directly in `03_Figures_Data/`).
